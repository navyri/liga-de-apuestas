Registros de Decisión (ADR)

Decisiones formales con opciones consideradas, alternativas descartadas y compromisos asumidos

ADR-001

Estilo arquitectónico

Monolito vs. monolito modular vs. microservicios puros vs. híbrida → se adopta la híbrida.

 ADR-002

Tecnología de mensajería

Kafka como broker único frente a RabbitMQ o dual: log particionado y consumer groups.

 ADR-003

Consistencia e idempotencia

ACID local, idempotencia por apuesta, mayores restos y reembolso sin ganadores.

Regenerar los entregables

Todo el material visual se genera desde fuentes versionadas en el repositorio

1 · DIAGRAMAS

cd herramientas && npm install
node herramientas/generar_diagramas.mjs
SVG + PNG en exportados/.

2 · DOCUMENTO TÉCNICO

python herramientas/generar_documento_tecnico.py
y exportar el PDF con Chrome headless desde el HTML intermedio.

3 · PRESENTACIÓN

Abrir presentacion/index.html en el navegador → Imprimir → Guardar como PDF (una página por slide).
